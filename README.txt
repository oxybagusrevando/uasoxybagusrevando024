WEBSITE INFORMASI ASAM URAT
===========================

Isi folder:
- index.php          : halaman Home
- profil.php         : profil penyakit
- gejala.php         : gejala penyakit
- penyebab.php       : penyebab dan faktor risiko
- pencegahan.php     : pencegahan
- penanganan.php     : penanganan
- konsultasi.php     : formulir konsultasi (validasi JavaScript dan PHP)
- kontak.php         : kontak dan sumber referensi
- config.php         : pengaturan nama website
- header.php         : bagian atas dan navigasi
- footer.php         : bagian bawah website
- assets/style.css   : desain website
- assets/script.js   : menu mobile dan validasi formulir

CARA MENJALANKAN DI KOMPUTER (XAMPP):
1. Ekstrak folder website_asam_urat.
2. Pindahkan folder ke dalam C:\xampp\htdocs\
3. Jalankan Apache melalui XAMPP.
4. Buka browser dan ketik: http://localhost/website_asam_urat/

CARA HOSTING:
1. Pastikan layanan hosting mendukung PHP.
2. Upload semua isi folder website_asam_urat ke folder public_html.
3. Buka domain yang sudah diarahkan ke hosting.

CATATAN:
- Form konsultasi adalah contoh pembelajaran. Data tidak disimpan ke database dan tidak dikirim ke email.
- Ganti alamat, nomor telepon, dan email pada kontak.php dengan data pengelola yang benar.
- Periksa kembali isi dan identitas sebelum dikumpulkan.
- Koneksi Google Fonts bersifat opsional; jika tidak tersedia, website tetap memakai font cadangan.
- Website ini adalah media edukasi, bukan alat diagnosis atau pengganti konsultasi tenaga medis.
